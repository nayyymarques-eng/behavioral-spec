# Glossary

What each thing in the product is today, in one line. When a screen file and this table disagree, this table wins, and the screen file is fixed in the same pull request. One name per thing, in the spec, the screens and the code.

| Term | What it is today | Rules | Latest decision |
|---|---|---|---|
| Request | A message from a person about their personal data: to see it, correct it, delete it or move it | BR-01 | D-01 |
| Due date | One month after the request reached the shop; three months once extended | BR-01, BR-02 | D-04 |
| Due soon | The 7 days before the due date | BR-07 | D-06 |
| Overdue | Past the due date and not answered | BR-03 | D-02 |
| Extension | Two more months, once, with a written reason | BR-02 | D-04 |
| Proof of identity | What the lead asks for when there is a reasonable doubt about who wrote | BR-05 | D-05 |
| Answered | The lead sent the answer from the shop's email and recorded the date | BR-04 | D-01 |
